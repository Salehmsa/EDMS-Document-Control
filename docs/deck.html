What a register cannot do on its own
1
Days-to-expire is frozen. A SharePoint calculated column using Today() stops updating the moment the row is last edited. Nothing errors. The column quietly drifts further from reality every day.
2
A single reminder date is not escalation. One date, one email, one recipient. No widening audience, no second channel, no proof it was ever delivered.
3
A missing document has no row. The register can only report on what it contains. If an entity must hold a certificate and nobody created the row, the register shows nothing wrong.
The proposal
المقترح — سبع طبقات

Seven layers on top of what already exists

1
Data model
10 lists. Document type is the policy engine — it carries validity, reminder ladder, approval chain, retention and sensitivity.
2
Status engine
A nightly flow stamps the real days-to-expire and status, replacing the broken calculated column.
3
Escalating alerts
A per-type ladder that widens audience and channel as expiry approaches, guarded against duplicate sends.
4
Approval chain
Sequential, driven by document type, recorded as evidence. Digital signature where an external party must rely on it.
5
Access control
Six roles — including a compliance officer who can correct but never delete, and delegation that expires by itself.
6
Security & compliance
Saudi PDPL first, then ISO 9001 clause 7.5.3 and ISO 27001. Labels, DLP, Conditional Access, real backup.
7
Executive reporting
One compliance health score — plus a measure that reveals when the automation itself has stopped running.

Why this works
Flows using only SharePoint, Outlook, Teams and Approvals run on rights seeded into Microsoft 365 — no extra licence.
The moment a flow touches HTTP, it becomes premium.
A Power Automate Process licence attaches to the flow, not to the person. One licence, unlimited users triggering it.
So every premium connector lives in two child flows owned by one service account.
!
Intent decays. A Power Platform DLP policy blocks premium connectors in the default environment, so nobody can accidentally add an HTTP action to a seeded flow and create a licence exception six months from now.

Alerting
سُلّم التنبيهات

Escalation widens the audience, not just the frequency

Two rules that keep it credible
SMS only inside the last seven days — used earlier it becomes ordinary, and an ordinary SMS alert is an ignored one.  ·  Every send is guarded by an idempotency key, so re-running the flow sends nothing twice.
Access control
الصلاحيات

Six roles — two of them exist to close real holes

System Administrator
مسؤول النظام
Full control. Two named people, elevated only when needed.
Compliance Officer
مسؤول الامتثال
Can correct anything. Can delete nothing — a custom role removes delete rights so evidence survives.
Document Owner
مالك الوثيقة
Creates and maintains documents in their own department. Roughly 25 people.
Approver
موجّه
Sees and decides only what is routed to them.
Reader
قارئ
Sees that a document exists and when it expires. Opens the file only if its sensitivity allows.
Delegate
مفوَّض مؤقت
Time-boxed cover during leave. Expires by itself — no cleanup step anyone can forget.
Permissions scale with departments, not documents. Metadata stays open to everyone; the files are partitioned by department and sensitivity. Per-item permissions would collapse past 5,000 documents.

Risk of building it badly
أعطال شائعة

What usually goes wrong — and why it will not here

1
The frozen Today()
A calculated column stops updating and quietly lies.
Stamped nightly; the dashboard alarms on any disagreement.
2
Duplicate alert storms
Re-run flows send the same alert twice; people filter the sender.
An idempotency key checked before every single send.
3
Silent flow death
The thing that raises alerts is the thing that died.
A watchdog escalates if no run summary appears in 26 hours.
4
Version history explosion
Writing every row nightly destroys the audit signal.
Write only where a value actually changed.
5
The 5,000-item threshold
Works with 200 rows, breaks in production two years later.
Nine indexed columns; every view filters on one.
6
Recycle bin as backup
93 days is not a backup policy.
A real backup product with a rehearsed restore drill.
All six share one signature: the system keeps looking healthy after it has stopped working. A green dashboard fed by stale data is worse than no dashboard, because it stops anyone asking the question.
